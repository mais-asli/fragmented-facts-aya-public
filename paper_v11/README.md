# Lost in Vocalization — anonymized manuscript version 11

This folder contains the anonymized v11 LaTeX source, bibliography, fonts, figure PDFs, analysis scripts and consolidated records. The named submission PDF is omitted for privacy. The scientific text, AI-assistance disclosure, outcomes and results are retained; author identities are replaced with generic labels.

Compile main.tex with XeLaTeX (xelatex, bibtex, xelatex, xelatex), or upload the typesetting assets to Overleaf. ../REPRODUCIBILITY.md documents the public research archive and commands. The full release adds the per-prompt pilot/held-out run folders required by the consolidation and layer-31 analysis; those raw folders are not duplicated in Git.

No new Aya inference was performed for v11. This version includes the layer-31 control and token-level uncertainty table introduced in v10, the corrected single-predictor baseline caption, and the more precise held-out Hebrew interval.
